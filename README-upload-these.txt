   On GitHub → IP-Reports → Add file → Upload files
   Drag the whole "uploads" folder (contains gitkeep).
   Commit.

2) gitignore file
   GitHub will not accept a drag-upload as ".gitignore" from a visible file name.
   Do this once:
   - Add file → Create new file
   - In the name box type exactly:  .gitignore
   - Open "gitignore" from this folder in TextEdit, copy all, paste into GitHub
   - Commit changes
